##Quoty — Smart Quote Generator

Quoty è un generatore di preventivi commerciali progettato per semplificare e velocizzare la creazione di proposte professionali. Permette di configurare servizi, condizioni contrattuali e valorizzazione economica, generando automaticamente un PDF pronto per il cliente.

#Funzionalità principali

Configurazione rapida di servizi e dispositivi con prezzi riservati e di listino
Generazione automatica del PDF con layout professionale
Esportazione e invio diretto al cliente

#Stack tecnologico

React + TypeScript
Vite
Tailwind CSS + shadcn/ui
@react-pdf/renderer per la generazione PDF
Firebase (Firestore + Authentication)
